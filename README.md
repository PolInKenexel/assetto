# Bienvenido al repositorio oficial de la App de Assetto 👋

Este es un proyecto escolar creado con la plantilla proporcionada por el Framework de trabajo de Expo React Native, usando el comando: [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Para iniciar:

1. Instala las dependencias del proyecto:

   ```bash
   npm install
   ```

   o de manera alternativa, si tienen Yarn:

   ```bash
   yarn install
   ```

2. Para probar Assetto:

   ```bash
   npx expo start
   ```
   
## ¿Qué es Assetto?

Assetto es una App para la creación de Setlists, listas de canciones para interpretar en programas musicales, presentaciones, conciertos, o cualquier otro tipo de espectáculo que requiera tocar en vivo, especialmente enfocado para músicos que trabajan de manera independiente, con recursos limitados o con muy mínimo apoyo. 
El atractivo principal de nuestra aplicación es almacenar tu repertorio personal de canciones que conoces como interpretar, y dejar que la aplicación, usando los datos de estas canciones, te ayude a crear tus listas de canciones por medio de recomendaciones que facilitan la selección de obras a interpretar. Especialmente útil si tienes tiempo limitado para poder estructurar nuevas listas que mantengan la coherencia temática y/o armónica durante toda la presentación.
